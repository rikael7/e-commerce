Sessão autenticada

Você está logado =)

Este projeto foi construído para demonstrar, em produção, um fluxo de autenticação com sessões: senhas com hash via bcrypt, gerenciamento de sessão com express-session e persistência em PostgreSQL. Esta página é protegida no back-end e não pode ser acessada por quem não estiver autenticado.

Node.js Express XSS Express-validator bcrypt express-session PostgreSQL
Rota protegida por middleware de sessão — qualquer tentativa de acesso sem autenticação é bloqueada no servidor.
